================================================================================
  OUTLAST VR
================================================================================

BEFORE YOU START

  Run Outlast once normally, so the game creates its settings files.

INSTALLING

  1. Find your Outlast folder. In Steam, right click Outlast, then Manage,
     then Browse local files. From there open  Binaries\Win64.

  2. Copy ALL of these files into that folder, next to OLGame.exe:

         Outlast-VR.bat
         d3d9.dll
         openxr_loader.dll
         outlastvr.ini

  3. Run Outlast-VR.bat from that folder to install.

  4. In Outlast's own settings, turn off motion blur and set graphics to whatever.

UNINSTALLING

  Run Outlast-VR.bat again and choose  [2] Uninstall.
